# JAC Omics And Bioinformatics (JACOB) Team
The **JACOB** Team is an internal unit belong to *Jun-An Chen Lab*, *Institute of Molecular Biology* (IMB), *Academia Sinica* Taiwan.

## Missions
* Advanced and customized omics **data analysis**
* Build and maintain **infrastructure** of data processing and data deployments for JAC Lab
* Compose **education** documents of data analysis and package comparisons fro JAC Lab
